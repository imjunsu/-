# Football Scout

유럽 5대리그 선수 데이터를 바탕으로 조건에 맞는 선수를 추천하고, 선수 기록과 리그별 특징을 비교하는 Streamlit 앱입니다.

## 주요 기능

- 포지션, 나이, 몸값 조건으로 선수 추천
- 선수 이름 검색
- 손흥민, 김민재, 이강인, 황희찬 등 주요 선수 한국어 이름 검색 지원
- 골, 도움, 출전 시간, 90분당 기록 확인
- 프리미어리그, 라리가, 세리에 A, 분데스리가, 리그 1 비교
- CSV 업로드 및 현재 데이터 다운로드

## 실행 방법

```powershell
pip install -r requirements.txt
streamlit run app.py
```

실행 후 브라우저에 표시되는 주소로 접속하면 됩니다.

## 데이터 사용 방식

앱은 먼저 같은 폴더의 `top5_leagues_player.csv` 파일을 찾습니다. 파일이 있으면 그 데이터를 사용하고, 없으면 FBref의 2025-2026 유럽 5대리그 선수 통계를 온라인으로 불러옵니다.

시장가치 컬럼이 있는 CSV를 쓰고 싶다면 아래 이름 중 하나로 컬럼을 넣으면 됩니다.

- `market_value_m`
- `value_m`
- `market_value`
- `몸값`
- `시장가치`

단위는 백만 유로(M) 기준입니다. 예를 들어 20M은 `20`으로 입력하면 됩니다.

## 권장 CSV 컬럼

- `player`: 선수 이름
- `age`: 나이
- `pos`: 포지션
- `nation`: 국적
- `squad`: 소속팀
- `comp`: 리그
- `mp`: 경기 수
- `starts`: 선발
- `minutes`: 출전 시간
- `gls`: 골
- `ast`: 도움
- `market_value_m`: 시장가치

CSV에 시장가치가 없을 경우 앱은 나이, 포지션, 출전 시간, 골, 도움을 바탕으로 계산한 `스카우트 예상가`를 표시합니다.
